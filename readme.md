# Complete Chess Guide Website

A comprehensive, interactive website with complete information on how to play chess, including instructions, moves, tactics, and strategies.

## 📋 Features

### 1. **Getting Started: Chess Basics**
- What is chess?
- The chess board (8x8 grid, coordinates)
- All 6 types of chess pieces with descriptions
- Piece values and quantities

### 2. **How Pieces Move**
- Detailed movement rules for each piece:
  - King (1 square in any direction)
  - Queen (any squares horizontally, vertically, diagonally)
  - Rook (horizontal and vertical)
  - Bishop (diagonal)
  - Knight (L-shaped)
  - Pawn (special forward/capture rules)

### 3. **Official Chess Rules**
- Starting position and setup
- Check and checkmate
- Stalemate
- Castling rules
- Other important rules (touch-move, illegal moves, draw conditions)

### 4. **Chess Tactics & Strategies**
- **10 Basic Tactical Motifs:**
  1. Fork
  2. Pin
  3. Skewer
  4. Discovered Attack
  5. Double Attack
  6. Removal of Defender
  7. Deflection
  8. Decoy
  9. Zugzwang
  10. Sacrifice

- **Opening Principles**
- **Middlegame Strategy**
- **Endgame Strategy**
- **Famous Chess Tactics Examples**

### 5. **Board Setup & Notation**
- Initial board position
- Algebraic notation (a-h, 1-8)
- How to write moves
- Move abbreviations and symbols

### 6. **Tips for Improvement**
- 10 practical tips for becoming a better chess player

## 🎨 Design Features

- **Responsive Design**: Works on desktop, tablet, and mobile devices
- **Modern UI**: Clean, professional interface with smooth animations
- **Easy Navigation**: Sticky navigation bar with smooth scrolling
- **Color Scheme**: Professional dark and gold theme
- **Visual Cards**: Information organized in easy-to-read cards
- **Hover Effects**: Interactive elements with smooth transitions
